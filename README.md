# 中华上下五千年 · 疆域变迁

一个交互式网页地图：从远古传说到当代，按时期展示中国历代疆域变化，以及每个时期的重大历史事件。

**在线访问：<https://liyucheng1997.github.io/367_lab-chinese-map/>**（例如直达唐朝：[#tang](https://liyucheng1997.github.io/367_lab-chinese-map/#tang)）

## 运行

纯静态页面，无需构建。在本目录启动任意静态服务器即可：

```bash
python -m http.server 8367
```

然后打开 <http://localhost:8367>。也可以直接双击 `index.html` 打开（数据以 JS 文件加载，不依赖 fetch）。

> 需要联网：Leaflet 地图库从 unpkg（失败时自动切换 bootcdn）加载，底图瓦片来自 Esri / 高德。离线时可在右上角选择"底图：无"，疆域多边形照常显示。

## 功能

- **24 个时期**：远古传说、夏、商、西周、春秋、战国、秦、西汉、东汉、三国、西晋、东晋十六国、南北朝、隋、唐、五代十国、北宋、南宋、元、明、清、晚清、中华民国、中华人民共和国。
- **疆域地图**：每个时期绘制主体王朝及同时期并立政权（匈奴、吐蕃、辽、西夏、金等），都护府/羁縻地区用虚线表示，晚清被割占领土用红色虚线标出。
- **大事记**：约 240 个事件，按政治、战争、文化、科技、对外交往、起义变乱分类，可筛选；点击事件会飞到地图对应位置并弹出说明。
- **时间轴**：底部按时期切换，上方彩条按真实时长比例显示；支持自动播放。
- **快捷键**：`←` / `→` 切换时期，空格键播放/暂停。网址带 `#tang` 这样的锚点可直接打开某个时期。
- **现代国界参照**：可叠加现代中国轮廓虚线，方便对比古今疆域。

## 目录结构

```
index.html        页面骨架
css/style.css     样式（含窄屏适配）
js/geo.js         海岸线锚点、常用边界路径、现代国界等地理底稿
js/data.js        各时期疆域多边形与事件数据
js/app.js         地图渲染与交互逻辑
```

## 修改数据

在 `js/data.js` 中每个时期是一个对象：

- `polities`：政权列表，`kind` 取值 `main`（主体王朝）、`neighbor`（并立政权）、`protectorate`（都护府/羁縻）、`lost`（被割占）、`culture`（文化区）；`rings` 为若干多边形，坐标顺序是 `[经度, 纬度]`。
- `events`：事件列表，`y` 为年份（负数为公元前），`c` 为类别（政/战/文/科/交/变），`at` 为 `[经度, 纬度]`。
- `view`（可选）：`[[西, 南], [东, 北]]`，指定切换到该时期时的地图视野。

沿海边界可以用 `C('yalu', 'beibu')` 这样的写法截取 `geo.js` 中的海岸线，保证各时期海岸一致。

## 说明

疆域边界参考通行历史地图概略绘制，属于示意性质，并非精确测绘；上古年代多为约数。适合科普与教学演示，不宜作为学术引用依据。
